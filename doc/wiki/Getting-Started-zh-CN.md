# 快速开始

## 1. 安装插件

1. 从 [Releases](https://github.com/chrislucy838-collab/zotero-research-copilot/releases) 下载 `Zotero-Research-Copilot-<版本>.xpi`。
2. 在 Zotero 中打开 **工具 → 附加组件**。
3. 打开齿轮菜单，选择 **从文件安装附加组件…**。
4. 选择 XPI，按提示重启 Zotero。

当前支持范围是 Zotero **10.0–10.x**。

## 2. 打开面板

重启后，Zotero Research Copilot 可以出现在：

- 选中条目后的文库条目面板；
- PDF 阅读器侧边栏；
- EPUB 阅读器侧边栏。

面板包含三个标签：

- **Discussion**：对话、上下文、历史、附件和导出；
- **Discover**：搜索公开学术索引并导入选中的论文；
- **Setting**：连接方式、模型、语言、翻译和高级选项。

## 3. 配置模型

在 **Setting** 中选择 OAuth provider 或 **API 方式**。

OAuth 通常按以下顺序操作：

```text
安装/更新环境 → OAuth 登录 → 刷新模型
```

API 方式至少需要 API Base URL 和 Model。只有端点要求认证时才填写 API Key。

## 4. 询问论文

打开条目或文档，在 Discussion 中提问。面板可以使用当前文档作为上下文。在阅读器中选中文本后点击 **Add Text**，可以明确加入这段原文。

比较多篇论文时：

1. 在输入框输入 `@`，搜索另一篇 Zotero 文献；或
2. 使用附件菜单，从 Zotero 集合中选择论文。

上下文标签会显示当前请求包含哪些论文。

## 5. 保存和继续工作

使用聊天历史控件新建、重命名、置顶、分支、重试、编辑或删除对话。通过回复菜单复制内容或保存为 Zotero 笔记，也可以导出完整聊天记录。

## 6. 发现论文

打开 **Discover**，输入关键词、标题、作者或 DOI，并选择一个或多个索引：

- OpenAlex
- Semantic Scholar
- Crossref

检查返回的元数据和重复状态，选择记录后指定 **My Library**、已有集合或新集合，再点击 **Import selected**。PDF 获取取决于索引是否提供开放获取地址。

## 7. 划词翻译

在设置中启用划词翻译并选择模型、目标语言，然后在 PDF 或 EPUB 阅读器中选中文本。可以设置为自动翻译，也可以在弹窗中手动触发。复制和添加到笔记按钮可按设置显示。

PDF 首次使用时可能建立本地冷启动缓存，包含精简概览和术语信息；EPUB 会围绕选区使用有界图书上下文。

## 8. 添加文件和图片

输入框支持上传、粘贴和拖拽文本、Markdown、代码、PDF 和图片。截图按钮可以截取阅读器中的区域。图片分析需要模型和端点支持多模态输入。

## 9. 常见排查

- **没有模型：**完成 OAuth 登录并刷新模型，或检查 API Base URL 和 API Key。
- **论文没有 PDF：**索引可能只提供元数据，或开放获取地址不可用。
- **上下文缺失：**确认当前阅读器标签正确，再点击 Add Text 或重新加入论文引用。
- **OAuth 失败：**运行安装/更新环境，查看 Setting 控制台，并检查 provider 账号和条款。
- **某功能不可用：**不同模型的能力不同，确认模型是否支持对应输入和接口。
