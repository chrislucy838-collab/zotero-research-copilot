# 功能与工作流

## Discussion 对话

Discussion 围绕 Zotero 中当前打开的文档工作，支持流式回答、快捷操作、模型选择、编辑/重试、会话分支和上下文管理。

一次请求可以组合：

- 当前 Zotero 条目或阅读器文档；
- 阅读器选中文本；
- 一篇或多篇额外 Zotero 论文；
- 截图和图片附件；
- 文本、Markdown、代码、PDF 或图片文件；
- 本地保存的对话记忆。

面板会保留论文归属，让回答更容易区分当前文档和补充文献。

## 证据与引用

当模型返回支持的论文/页码引用标记时，面板会解析这些标记，并将其关联到对应证据上下文。引用可以用于检查和定位，而不只是装饰文本。

引用质量取决于模型以及实际提供的文档文本。插件不会替模型验证没有被上下文支撑的事实。

## PDF 与 EPUB 检索

文档层针对 PDF 和 EPUB 使用不同适配器。插件提取文本、划分有界检索单元，并保留来源定位信息和章节元数据。EPUB 优先使用 EPUB 3 navigation 或 EPUB 2 NCX 目录；结构不完整时使用语义标题和阅读顺序作为后备。

当文档包含匹配的章节标签时，明确的章节请求会优先在本地路由；模糊问题则检索相关片段，默认不会直接发送整本书。

## 多论文研究

在 Discussion 输入框中输入 `@` 搜索 Zotero 文献，或打开附件菜单从集合中选择论文。每篇论文都会显示为独立的上下文标签，可以单独移除。

适合用于比较方法、追踪概念演变、核对不同论文的论断，以及从一个集合建立阅读顺序。

## Discover 与导入

Discover 会并行搜索 OpenAlex、Semantic Scholar 和 Crossref，将结果按 DOI、标题和其他标识符归并去重。导入前会标出当前 Zotero 文库中已经存在的记录。

导入流程允许你：

1. 查看标题、作者、年份、期刊/会议、DOI、摘要和 PDF 状态；
2. 只选择需要的记录；
3. 指定 My Library、已有集合或新集合；
4. 取消较长的导入任务，同时保留已经创建的条目。

元数据和 PDF 可用性来自公开索引，没有任何结果保证提供可下载全文。

## 文件、截图与多模态模型

输入框支持上传、拖拽和剪贴板粘贴文件。截图功能可截取阅读器区域，用于讨论图表或公式。选中的模型必须支持相应输入类型，文本模型不会因为添加了图片就自动获得视觉能力。

兼容的 provider 可能返回图片生成结果，实际可用性取决于 provider、模型、端点和账号权限。

## 划词翻译

划词翻译使用对话面板共享的 provider 和模型列表。它可以在选中文本后自动运行，也可以等待弹窗中的按钮触发；源语言支持自动识别，目标语言可以配置。

PDF 首次使用时可以建立本地精简概览和术语缓存；EPUB 会以选区为锚点建立有界图书上下文。复制和添加到笔记按钮由设置控制。

## 本地保存与笔记

聊天记录保存在 Zotero 本地数据库，并按文库和会话上下文隔离。用户可以新建、重命名、置顶、分支、编辑、重试、导出和删除对话，也可以将回复或完整聊天历史转换为 Zotero 笔记。

记忆系统在本地保存信息，进行相似内容去重、相关性排序，并在写入前过滤疑似提示注入内容。它是辅助层，不能替代研究笔记和来源核验。
